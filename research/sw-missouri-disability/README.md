# Southwest Missouri disability navigation research

This folder is not part of the Snoozetown site. It is a safe copy of research notes for a
separate project: a navigator guide, an eligibility screener, and a gap and policy report for
caregivers of disabled people in Springfield and Southwest Missouri.

Status on 27 Oct 2026:

- Complete: all eight research files (01 to 08) and three fact checks (09, 09b, 09c).
- Published (private): the Ozarks Care Navigator page and the report "Disability Service Gaps in
  Southwest Missouri". Copies are in `outputs/`.
- `build/` holds the page template, the checked data (`data/*.json`), and `build.py`, which
  checks the data and builds the page: `python3 -I build/build.py build/data out.html`.
- Some facts are marked "Call to confirm". A professional should review the page before
  families use it.

`00-team-brief.md` holds the scope, rules, and file format for each agent.
`00-data-schema.md` holds the data format for the page.
